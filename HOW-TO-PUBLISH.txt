Option A · Netlify — easiest · الأسهل
  1 · app.netlify.com/drop  →  drag this folder
  2 · Site settings → Domain management → Add a domain → www.smart-systems.com.co
  3 · Netlify shows the DNS records. Put them at your registrar · see DNS below
  4 · Delete CNAME from this folder — Netlify does not use it

Option B · GitHub Pages
  1 · Create a public repository on github.com
  2 · Add file → Upload files → all files here → Commit
  3 · Settings → Pages → Branch main · root → Save
  4 · Settings → Pages → Custom domain → www.smart-systems.com.co → Save
  5 · Tick "Enforce HTTPS" once it becomes available

DNS at your registrar · سجلات DNS لدى مزود النطاق
  Netlify
    CNAME   www    <your-site>.netlify.app
    ALIAS/ANAME or A for the bare domain — Netlify shows the exact value
  GitHub Pages
    CNAME   www    <your-github-username>.github.io
